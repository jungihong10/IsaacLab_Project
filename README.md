# IsaacLab_Project
A simulation-first PoC pipeline using NVIDIA IsaacLab for real-to-sim and sim-to-real workflows and NVIDIA Cosmos for synthetic data generation, used to test and fine-tune VLAs in simulation before deploying them on real robots.
